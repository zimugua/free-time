**项目架构 - 活动规划Agent（2026-04-23更新）**
- 技术栈：Python + Gradio，UI组件数19个（含output_box）
- 新流程（9步）：解析→搜索活动→搜索餐厅→匹配座位→餐前空隙→用餐确认→餐后空隙→方案对比→预订生成
- 餐前活动校验：缓冲15min + A→B路程 + B时长 + B→餐厅路程 ≤ 餐前空隙，超出≤30min标记△
- 餐后活动校验：餐厅→活动路程 + 缓冲15min + 活动时长 ≤ 餐后空隙
- 等待就餐展示：用户选择等到就餐时间时，行程中展示等待段落（>15min才展示），含等待时长和建议
- UI组件顺序：output_box, act(3), premeal(3), meal(3), rest(3), postmeal(3), plan(3)
- Mock数据独立包：data/activities.py, data/restaurants.py
